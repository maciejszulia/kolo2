# kolo2

Data analysis tasks in Python from a test (version A): pandas, matplotlib and seaborn on a car data set.

University coursework from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2021 (commits on 1 June 2021).

## Contents

- `pythonProject7/zad1-pandas.py`: loads `cars.csv` into a pandas data frame and selects rows by weight.
- `pythonProject7/zad2-matplotlib.py`: reproduces the chart from `zad2a.png` in matplotlib; `zad3-seaborn.py`: a seaborn chart.
- `pythonProject7/zad4.py`: a pie chart of cylinder counts in Ford cars.
- `pythonProject7/cars.csv`, `dane.7z`: data; `wykres.png`: a chart.
- `pythonProject7/venv/`: a Windows Python virtual environment (6 179 files) committed with the project.

The repository also contains course materials: the task sheet `pythonProject7/Wersja_A.pdf` and the chart to reproduce, `pythonProject7/zad2a.png`.

## Running

The scripts need pandas, matplotlib and seaborn, which this machine does not have, so I did not run them in November 2026.
